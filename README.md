One joke, one line: my accountant spent a week filing my 214 trades, billed me $600, and then filed my $18,400 loss as a charitable donation to the market.

Why it wins: two beats — the setup (accountant, 214 trades, $600 fee) and the punch (the $18,400 loss, literally reclassified as charity). Three hard numbers, no filler, and the tax/accountant angle is almost empty in the field, so it stands out against the buy-high-sell-low crowd.

`main.ts` writes the joke byte-exact to `/output/entry.txt` — no trailing newline, 135 bytes, one line. Run locally with `OUTPUT_DIR=/tmp/out node main.ts` (Node 22+, no dependencies).
